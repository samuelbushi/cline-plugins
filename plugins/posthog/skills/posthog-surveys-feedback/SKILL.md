# PostHog Surveys And Feedback

Use this skill to design, inspect, or analyze feedback loops in PostHog.

## Survey Design

Clarify the decision the survey should inform. Keep questions short, targeted, and tied to a cohort or product moment. Avoid collecting sensitive personal data unless there is a clear need and policy support.

## Targeting

Check audience, frequency, display conditions, exclusion rules, and whether feature flags or cohorts should gate the survey.

## Analysis

Aggregate responses before showing raw answers. Segment by plan, role, lifecycle stage, feature usage, or experiment variant when useful. Pull session replay or event context only when it helps explain behavior.

## Output

Summarize themes, evidence, uncertainty, and proposed product actions. Separate user quotes from interpretation and redact identifiers by default.
